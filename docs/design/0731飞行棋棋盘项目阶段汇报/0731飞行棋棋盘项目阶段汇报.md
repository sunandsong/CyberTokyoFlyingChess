# 0731飞行棋棋盘项目阶段汇报

主要修改

1. 调整了整个棋盘的布局和形式，使其紧凑、方向明确

2. 设计了不同的棋盘格表现形式

3. 设计了棋子

4. 增加了异步在线对战/影子对手的棋子展示方式

### 异步在线

玩家在游玩中，棋盘上出现幽灵对手，是其他玩家被记录下的游戏轨迹，幽灵对手顶部显示头像，底部显示将其踩掉能获得的奖励。

### 循环形式

在踩到拐角箭头地格时，走上传送带，并最终抵达中心建筑，哥斯拉。
根据循环次数，哥斯拉会产生惊醒\-愤怒\-喷吐死光等，或是愉悦顺服等表情动画，随后全地图奖励重制，并提升奖励等级（金币变钞票），增加奖励密度（卡片碎片、骰子/体力奖励、神秘事件等）。
